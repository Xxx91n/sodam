# 托盘点击按平台惯例，而非三端硬性统一

状态：accepted
日期：2026-10-20

Windows 与 Linux 的托盘左键单击聚焦/唤起主窗口，右键打开快捷菜单；macOS 保持系统惯例，左键打开快捷菜单。我们没有把三端硬性统一，因为 Windows/Linux 的官方规范与主流桌面应用都把左键视为“打开应用”，而 macOS 的菜单栏图标按 HIG 应当打开菜单；强行统一会让 macOS 用户必须右键才能打开菜单，逆着系统肌肉记忆。代价是三端行为不完全一致；收益是每端都符合用户预期与平台规范。

## Considered Options

- 三端统一左键聚焦：一致性更强，但违背 macOS HIG，实现成本更高。
- 只改 Windows：改动最小，但 Linux 已符合该心智模型，没有必要回退。

## Consequences

- macOS 左键菜单必须保留「显示主窗口」入口（D-003）。
- Windows/Linux 左键不承担菜单职责；双击不定义独立行为（D-002）。
